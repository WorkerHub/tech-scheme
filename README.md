# tech-scheme

本仓库是《WorkerHub 通用技术方案》的**唯一真源（source of truth）**，同时按 Agent Skills 规范组织为一个 Skill：改方案 = 改本仓库文件并推送，团队经 Skills 库关联本仓库同步。

## 内容

| 文件 | 是什么 | 落点 |
|---|---|---|
| `tech-scheme/SKILL.md` | Skill 入口：适用范围、红线摘要与章节索引 | 团队 Skills 库，关联本仓库后自动更新 |
| `tech-scheme/references/tech-scheme.md` | 方案全文（§1–§12 与版本历史） | 随 Skill 按需读取 |

## 修改与发布流程

1. 在本仓库改文件（经 PR 或直接提交 main，以仓库约定为准），提交说明写清改了哪一节、为什么。
2. 同步后用 MCP 回读 Skill 入口与全文，与本仓库文件逐字核对一致才算发布完成。
